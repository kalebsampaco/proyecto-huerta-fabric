# Seguridad de capturas

Las capturas de la arquitectura y el flujo estan incrustadas en la galeria del README principal. Guarda aqui las nuevas imagenes y actualiza esa galeria cuando sustituyas una captura.

Antes de publicar, verifica que no aparezcan connection strings SAS, claves, tokens, correos, IDs privados ni datos de acceso. En especial, no captures la pagina **SAS Key Authentication** de Kafka mientras las credenciales esten visibles.
